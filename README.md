Tic-Tac-Toe
A simple two-player Tic-Tac-Toe game made with plain HTML, CSS and JavaScript. This is my submission for VOSC Activity 1.

How to run
Download or clone this repository.
Open index.html in any browser (just double-click it).
No installation or server needed.

git clone https://github.com/<your-username>/VOSC-Activity-1.git
How to play
Two players share the same screen. Who goes first is picked randomly each game, then you take turns.
Click an empty box to place your mark.
Get 3 in a row (horizontal, vertical or diagonal) to win.
If all 9 boxes are filled and nobody has 3 in a row, it's a draw.
The winning boxes turn green.
New game clears the board but keeps the score.
Reset score sets the score back to zero and clears the board.
Files
index.html - the page structure
style.css - the styling
script.js - the game logic
What I used
Only HTML, CSS and vanilla JavaScript. No libraries or frameworks.
